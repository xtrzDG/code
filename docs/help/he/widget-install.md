# צ׳אט באתר

הצ׳אט באתר פעיל מההתחלה. מבקרים לוחצים על הכפתור בפינת האתר שלכם ומדברים עם העוזר בשפה שלהם.

## הוספה לאתר

1. פתחו את **עוזר ← [ערוצים](cabinet:assistant/channels)** ומצאו את **הקוד לאתר שלכם**.
2. לחצו על **העתקת הקוד**.
3. הדביקו אותו לפני תגית הסגירה ‎`</body>`‎ בכל עמוד, או בהגדרת „קוד מותאם אישית” של בונה האתרים שלכם (ל-WordPress, Tilda, Wix, Shopify ואחרים יש הגדרה כזו).
4. פתחו את האתר ובדקו שכפתור הצ׳אט מופיע.

## המראה שלו

תחת **איך הצ׳אט נראה באתר שלכם** בחרו את צבע המותג ואת הפינה של הכפתור. **תצוגה מקדימה חיה** מראה את הצ׳אט כפי שהמבקרים רואים אותו, עוד לפני השמירה.

## אין לכם אתר?

**ערוצים ← שיתוף** נותן לכם את הקישור לדף הצ׳אט שלכם, קוד QR (PNG או SVG) וכרטיס להדפסה לשולחנות, לדלפק או לדלת. שימו את הקישור בפרופיל ה-Instagram, ברישום ב-Google Maps או בחתימת הדוא״ל.

> הקוד לא מכיל סודות: בטוח להדביק אותו בכל מקום באתר שלכם.
