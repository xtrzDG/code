# הפניית שיחות

הצוות עדיין עונה ראשון. השיחות שהוא מחמיץ, או שמגיעות כשהקו תפוס או שהטלפון כבוי, עוברות לעוזר: הוא עונה, קובע הזמנות ושולח לכם סיכום של השיחה.

## הפעלה

קודם צריך את המספר של העוזר: חברו את ערוץ **טלפון** ב**עוזר ← [ערוצים](cabinet:assistant/channels)**. אז העמוד מציג את הקודים עם המספר שלכם כבר בפנים.

קחו את הטלפון עם כרטיס ה-SIM שאליו הלקוחות מתקשרים, חייגו כל קוד ולחצו על חיוג:

| מתי | קוד |
| --- | --- |
| אתם לא עונים | `**61*number#` |
| הקו תפוס | `**67*number#` |
| הטלפון כבוי או מחוץ לכיסוי | `**62*number#` |
| כיבוי כל ההפניות | `##002#` |

אחרי כל קוד המתינו לאישור של המפעיל על המסך. אחר כך בדקו: התקשרו למספר שלכם מטלפון אחר ואל תענו; העוזר אמור לענות.

## לפי מפעיל

- **Magti** מפרסמת בדיוק את הקודים האלה (‎*61 אין מענה, ‎*67 תפוס, ‎*62 לא זמין).
- **Silknet** ו-**Cellfie**, ורוב המפעילים במדינות אחרות, מקבלים את אותם קודי GSM סטנדרטיים. אם קוד לא עובד, המפעיל יכול להפעיל הפניה באפליקציה שלו או דרך שירות הלקוחות.

## טוב לדעת

- קווים נייחים ומרכזיות משרדיות (PBX) מגדירים הפניה בהגדרות שלהם; פנו למי שמתחזק אותם.
- אם תנתקו את ערוץ הטלפון, חייגו גם `##002#`, אחרת המתקשרים ישמעו שהמספר אינו זמין.
- ב**הגדרות ← [שיחות טלפון](cabinet:settings/calls)** אפשר לשלוח הודעה בחזרה למתקשרים שלא הצליחו לעבור.
