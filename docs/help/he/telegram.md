# Telegram

הלקוחות שלכם כותבים לבוט Telegram משלכם, עם שם העסק והתמונה שלו, והעוזר עונה שם.

## חיבור

1. פתחו את ‎**@BotFather** ב-Telegram ושלחו `/newbot`.
2. בחרו שם (שם העסק שלכם) ושם משתמש שמסתיים ב-`bot`, למשל `cafe_batumi_bot`.
3. BotFather שולח מפתח שנראה כמו `123456789:AAH…`. העתיקו אותו.
4. בלוח הבקרה פתחו את **עוזר ← [ערוצים](cabinet:assistant/channels)**, לחצו על **חיבור** בכרטיס של Telegram והדביקו את המפתח.

זה הכול: כתבו לבוט מהטלפון שלכם והעוזר יענה.

## טוב לדעת

- שמרו את המפתח בסוד: מי שמחזיק בו שולט בבוט. לוח הבקרה שומר אותו מוצפן ולעולם לא מציג אותו שוב.
- כדי לשנות את התמונה או התיאור של הבוט, השתמשו ב-`/setuserpic` וב-`/setdescription` ב-‎@BotFather.
- אם תשלחו `/revoke` ב-‎@BotFather, המפתח הישן מפסיק לעבוד: הזינו את החדש דרך **עדכון הפרטים**.
- תשובות הצוות מ[תיבת ההודעות](inbox) מגיעות ללקוח באותו צ׳אט ב-Telegram.
