# פרטיות והנתונים של הלקוחות שלכם

אתם מחליטים למה נאספים נתוני לקוחות; אנחנו מעבדים אותם עבורכם לפי הסכם עיבוד הנתונים (DPA).

## ההסכם

קראו ואשרו את ההסכם ב**הגדרות ← [פרטיות](cabinet:settings/privacy)**. העוזר עולה לאוויר רק אחרי שאחד הבעלים מאשר אותו. הטקסט זמין בגאורגית, ברוסית ובאנגלית.

## לקוח מבקש את הנתונים שלו

1. פתחו את **הגדרות ← [פרטיות](cabinet:settings/privacy)** ומצאו את הלקוח לפי שם או טלפון.
2. **ייצוא** נותן את כל מה שנשמר עליו בקובץ אחד.
3. **מחיקה** מוחקת לצמיתות את השיחות, פרטי הקשר וההקלטות שלו.

## מי ראה מה

**הגדרות ← [יומן פעולות](cabinet:settings/audit)** מציג כל צפייה ושינוי במידע אישי: מי, מה ומתי. כשהתמיכה של הפלטפורמה נכנסת ללוח הבקרה שלכם לבקשתכם, גם זה נרשם, ואתם רואים פס התראה כל הזמן.

## טוב לדעת

- העוזר אומר שהוא AI בשפת הלקוח בתחילת השיחה.
- הקלטות שיחות נשמרות רק כל עוד תקופת השמירה מאפשרת, והן מוצפנות.
- הנתונים של הלקוחות שלכם נשמרים באיחוד האירופי.
