# როგორ დავიწყოთ

ასისტენტი კლიენტებს პასუხობს საიტის ჩატში, Telegram-ში, WhatsApp-ში, Instagram-სა და Messenger-ში და ტელეფონით, ჯავშნის ვიზიტებს და საჭიროების შემთხვევაში ადამიანს იძახებს. აი, ყველაზე მოკლე გზა მომუშავე ასისტენტამდე.

## 1. შექმენით ასისტენტი

დააჭირეთ **AI ასისტენტის შექმნა** და უპასუხეთ რვა მოკლე კითხვას: რა ბიზნესია, სად მდებარეობს, რას სთავაზობთ და რა ფასად, სამუშაო საათები და ჯავშნის წესები, ვის დაუძახოს, როცა ადამიანია საჭირო, და სად გწერენ კლიენტები. ყველაფერი წერისას ინახება — შეგიძლიათ შეჩერდეთ და მოგვიანებით დაბრუნდეთ.

## 2. გამოსცადეთ კლიენტებზე ადრე

ეკრანზე **გამოცდა** მისწერეთ ისე, როგორც კლიენტი მისწერდა: იკითხეთ ფასი, თავისუფალი დრო, მისამართი. რეალურ კლიენტებთან არაფერი იგზავნება. თუ პასუხი არასწორია, გაასწორეთ ფაქტი [ბიზნესის პროფილში ან ცოდნაში](teach-your-assistant) და კვლავ იკითხეთ.

## 3. გაუშვით

დააჭირეთ **გაშვება**. ჯერ ასისტენტი სატესტო საუბრებით მოწმდება; თუ რამე აკლია, ეკრანი გეტყვით, რა, და გახსნის გვერდს, სადაც ამის გასწორება შეიძლება. საცდელი პერიოდი გაშვებიდან იწყება, ასე რომ მისი ყოველი დღე რეალურ კლიენტებთან მუშაობს.

## 4. დააკავშირეთ არხები

საიტის ჩატი მაშინვე მუშაობს. დანარჩენები დაკავშირდება აქ: **ასისტენტი → [არხები](cabinet:assistant/channels)**. [Telegram](telegram) ორ წუთს მოითხოვს, [WhatsApp-სა](whatsapp) და [Instagram-ს და Messenger-ს](instagram-messenger) Meta-ს ბიზნეს-ანგარიში სჭირდება, ხოლო [ზარების გადამისამართება](call-forwarding) გამოტოვებულ ზარებს ასისტენტს გადასცემს.

## 5. მოიწვიეთ გუნდი და ჩართეთ შეტყობინებები

**პარამეტრები → [გუნდი](cabinet:settings/team)** — მოიწვიეთ ისინი, ვინც კლიენტებს პასუხობს. **პარამეტრები → [შეტყობინებები](cabinet:settings/notifications)** — ჩართეთ შეტყობინებები ტელეფონზე, რომ მაშინვე გაიგოთ, როცა კლიენტს ადამიანი სჭირდება.

> რამე ვერ გამოგივიდათ? გახსენით **დახმარება და მხარდაჭერა** ანგარიშის მენიუში: მოგვწერეთ WhatsApp-ში, Telegram-ში ან ელფოსტით — ადამიანი გიპასუხებთ.
