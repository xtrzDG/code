# ზარების გადამისამართება

თანამშრომლები კვლავ პირველები პასუხობენ. ზარები, რომლებიც გამოტოვეს, ან რომლებიც შემოვიდა, როცა ხაზი დაკავებულია ან ტელეფონი გამორთულია, ასისტენტს გადაეცემა: ის პასუხობს, ჯავშნის და ზარის შეჯამებას გიგზავნით.

## როგორ ჩავრთოთ

ჯერ ასისტენტის ნომერი გჭირდებათ: დააკავშირეთ არხი **ტელეფონი** აქ: **ასისტენტი → [არხები](cabinet:assistant/channels)**. ამის შემდეგ გვერდი გაჩვენებთ კოდებს თქვენი ნომრით.

აიღეთ ტელეფონი იმ SIM ბარათით, რომლის ნომერზეც კლიენტები რეკავენ, აკრიფეთ თითოეული კოდი და დააჭირეთ დარეკვას:

| როდის | კოდი |
| --- | --- |
| არ პასუხობთ | `**61*ნომერი#` |
| ხაზი დაკავებულია | `**67*ნომერი#` |
| ტელეფონი გამორთულია ან დაფარვის გარეთაა | `**62*ნომერი#` |
| ყველა გადამისამართების გაუქმება | `##002#` |

ყოველი კოდის შემდეგ დაელოდეთ ოპერატორის დადასტურებას ეკრანზე. შემდეგ შეამოწმეთ: დარეკეთ თქვენს ნომერზე სხვა ტელეფონიდან და არ უპასუხოთ — ასისტენტმა უნდა უპასუხოს.

## ოპერატორების მიხედვით

- **Magti** სწორედ ამ კოდებს აქვეყნებს (*61 — არ პასუხობს, *67 — დაკავებულია, *62 — მიუწვდომელია).
- **Silknet** და **Cellfie**, ისევე როგორც სხვა ქვეყნების ოპერატორების უმეტესობა, იმავე სტანდარტულ GSM კოდებს იღებს. თუ კოდი არ იმუშავა, ოპერატორმა შეიძლება გადამისამართება თავის აპლიკაციაში ან მხარდაჭერის მეშვეობით ჩართოს.

## კარგია იცოდეთ

- სტაციონარული ტელეფონები და ოფისის სატელეფონო სადგურები (PBX) გადამისამართებას საკუთარ პარამეტრებში აწყობენ — ჰკითხეთ მათ, ვინც მათ ემსახურება.
- თუ არხ „ტელეფონს“ გათიშავთ, აკრიფეთ `##002#`-იც, თორემ დამრეკები გაიგებენ, რომ ნომერი მიუწვდომელია.
- **პარამეტრები → [ზარები](cabinet:settings/calls)**-ში შეგიძლიათ ჩართოთ შეტყობინება მათთვის, ვინც ვერ დაგირეკათ.
