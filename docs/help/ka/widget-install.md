# საიტის ჩატი

საიტის ჩატი თავიდანვე ჩართულია. ვიზიტორები საიტის კუთხეში ღილაკს აჭერენ და ასისტენტს საკუთარ ენაზე ესაუბრებიან.

## როგორ დავამატოთ საიტზე

1. გახსენით **ასისტენტი → [არხები](cabinet:assistant/channels)** და იპოვეთ **საიტის ჩატის კოდი**.
2. დააჭირეთ **კოდის კოპირება**.
3. ჩასვით ის დამხურავი ტეგის `</body>` წინ ყველა გვერდზე, ან საიტის კონსტრუქტორის პარამეტრში „საკუთარი კოდი“ (ის აქვს WordPress-ს, Tilda-ს, Wix-ს, Shopify-ს და სხვებს).
4. გახსენით საიტი და შეამოწმეთ, რომ ჩატის ღილაკი გამოჩნდა.

## გარეგნობა

განყოფილებაში **როგორ გამოიყურება ჩატი საიტზე** აირჩიეთ ბრენდის ფერი და ღილაკის კუთხე. **ცოცხალი გადახედვის გახსნა** ჩატს ისე გაჩვენებთ, როგორც ვიზიტორები ხედავენ, ჯერ კიდევ შენახვამდე.

## საიტი არ გაქვთ?

**არხები → გაზიარება** მოგცემთ ბმულს თქვენს ჩატის გვერდზე, QR კოდს (PNG ან SVG) და დასაბეჭდ ბარათს — მაგიდებისთვის, დახლისთვის ან კარისთვის. დაამატეთ ბმული Instagram-ის პროფილში, Google Maps-ის ბარათში ან ელფოსტის ხელმოწერაში.

> კოდში საიდუმლო არაფერია: შეგიძლიათ თამამად ჩასვათ საიტის ნებისმიერ ადგილას.
