# კონფიდენციალურობა და კლიენტების მონაცემები

რა მიზნით გროვდება კლიენტების მონაცემები, თქვენ წყვეტთ; ჩვენ მათ თქვენი დავალებით ვამუშავებთ მონაცემთა დამუშავების ხელშეკრულების (DPA) შესაბამისად.

## ხელშეკრულება

წაიკითხეთ და მიიღეთ DPA აქ: **პარამეტრები → [კონფიდენციალურობა](cabinet:settings/privacy)**. ასისტენტი მუშაობას მხოლოდ მას შემდეგ იწყებს, რაც მფლობელი მას მიიღებს. ტექსტი ქართულად, რუსულად და ინგლისურად არის.

## კლიენტი თავის მონაცემებს ითხოვს

1. გახსენით **პარამეტრები → [კონფიდენციალურობა](cabinet:settings/privacy)** და იპოვეთ კლიენტი სახელით ან ტელეფონით.
2. **ექსპორტი** — ყველაფერი, რაც მასზე ინახება, ერთ ფაილად.
3. **წაშლა** — მისი საუბრები, კონტაქტები და ზარის ჩანაწერები სამუდამოდ იშლება.

## ვინ რა ნახა

**პარამეტრები → [მოქმედებების ჟურნალი](cabinet:settings/audit)** აჩვენებს პერსონალური მონაცემების ყოველ ნახვასა და ცვლილებას: ვინ, რა და როდის. თუ პლატფორმის მხარდაჭერა თქვენი თხოვნით თქვენს კაბინეტში შედის, ესეც ჩანს, ხოლო მთელი ამ ხნის განმავლობაში გვერდების თავზე ზოლი ჩანს.

## კარგია იცოდეთ

- საუბრის დასაწყისში ასისტენტი კლიენტის ენაზე ამბობს, რომ ის ხელოვნური ინტელექტია.
- ზარის ჩანაწერები მხოლოდ შენახვის ვადის ფარგლებში ინახება და დაშიფრულია.
- თქვენი კლიენტების მონაცემები ევროკავშირში ინახება.
