# Telegram

კლიენტები სწერენ თქვენს საკუთარ Telegram-ბოტს — თქვენი ბიზნესის სახელითა და ფოტოთი — და ასისტენტი იქ პასუხობს.

## დაკავშირება

1. გახსენით **@BotFather** Telegram-ში და გაგზავნეთ `/newbot`.
2. აირჩიეთ სახელი (ბიზნესის სახელი) და მომხმარებლის სახელი, რომელიც `bot`-ით მთავრდება, მაგალითად `cafe_batumi_bot`.
3. BotFather გამოგიგზავნით ტოკენს, რომელიც ასე გამოიყურება: `123456789:AAH…`. დააკოპირეთ.
4. კაბინეტში გახსენით **ასისტენტი → [არხები](cabinet:assistant/channels)**, Telegram-ის ბარათზე დააჭირეთ **დაკავშირება** და ჩასვით ტოკენი.

მზადაა: მისწერეთ თქვენს ბოტს საკუთარი ტელეფონიდან — ასისტენტი გიპასუხებთ.

## კარგია იცოდეთ

- ტოკენი საიდუმლოდ შეინახეთ: ვისაც ის აქვს, ბოტს ის მართავს. კაბინეტი მას დაშიფრულად ინახავს და აღარასდროს აჩვენებს.
- ბოტის ფოტო და აღწერა @BotFather-ში იცვლება ბრძანებებით `/setuserpic` და `/setdescription`.
- თუ @BotFather-ში `/revoke`-ს გაგზავნით, ძველი ტოკენი აღარ იმუშავებს: ახალი შეიყვანეთ **მონაცემების განახლება**-ით.
- თანამშრომლების პასუხები [შემოსულიდან](inbox) კლიენტს იმავე Telegram-ჩატში მისდის.
