# შემოსული

ყველა არხის ყველა საუბარი ერთ ადგილას. უმეტესობას ასისტენტი პასუხობს; შემოსულში ჩანს ის საუბრები, რომლებსაც თქვენ სჭირდებით.

## ჩანართები

- **ადამიანის დახმარება**: ასისტენტმა ადამიანი დაუძახა — მიზეზითა და სისწრაფით.
- **მოთხოვნები**: რასაც კლიენტები ითხოვდნენ და რისი გაკეთებაც ასისტენტს თავად არ შეუძლია (გადარეკვა, ჯგუფური ჯავშანი, კითხვა მფლობელთან).
- **ჩემი** და **დაუნიშნავი**: გუნდში ვინ რას უძღვება.
- **ყველა**: ყველა საუბარი, ძიებითა და ფილტრებით.

## პასუხი

გახსენით საუბარი და დაწერეთ ქვემოთ ველში: შეტყობინება კლიენტს იმ არხში მიუვა, სადაც მან მოგწერათ. აკრიფეთ `/`, რომ სწრაფი პასუხი ჩასვათ (ისინი აწყობილია აქ: **პარამეტრები → [სწრაფი პასუხები](cabinet:settings/quick-replies)**). დააჭირეთ **მოგვარდა**, როცა კლიენტმა მიიღო ის, რაც სურდა.

## გუნდური მუშაობა

საუბარი მის სათაურში დანიშნეთ საკუთარ თავზე ან კოლეგაზე. გვერდითა პანელის შენიშვნებს მხოლოდ გუნდი ხედავს — ისინი არც კლიენტს და არც ასისტენტს არ მიუდის.

## რომ არაფერი გამოგრჩეთ

ჩართეთ შეტყობინებები აქ: **პარამეტრები → [შეტყობინებები](cabinet:settings/notifications)** — ამ მოწყობილობაზე (push), ხოლო თანამშრომლების კონტაქტებისთვის ელფოსტით, SMS-ით ან Telegram-ით, მშვიდი საათებით.

> საუბარში არასწორი პასუხია? [ასწავლეთ ასისტენტს](teach-your-assistant), რომ შემდეგ ჯერზე სწორად უპასუხოს.
