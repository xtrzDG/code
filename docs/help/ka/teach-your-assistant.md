# როგორ ვასწავლოთ ასისტენტს

ასისტენტი მხოლოდ იმას პასუხობს, რაც თქვენ უთხარით. თუ რამე არ იცის, ასეც ამბობს და ადამიანს იძახებს; ფასებსა და დაპირებებს არ იგონებს.

## სად ინახება მისი ცოდნა

- **ასისტენტი → [ბიზნესის პროფილი](cabinet:assistant/profile)**: ადგილი, რას სთავაზობთ, საათები და ჯავშნები, ადამიანები, წესები. ყოველი ბარათი იმავე ეკრანებს ხსნის, რაც შექმნისას, და ცვლილებებს წერისას ინახავს.
- **ასისტენტი → [ცოდნა](cabinet:assistant/knowledge)**: კერძები, მომსახურებები, პაკეტები, პასუხები ხშირ კითხვებზე და წესები. მენიუს ატვირთვა შეიძლება ფოტოდან ან PDF-იდან, ან მისი წაკითხვა თქვენი საიტიდან.
- **ცოდნა → კითხვები**: რას კითხულობდნენ კლიენტები ისე, რომ ასისტენტმა ვერ უპასუხა. უპასუხეთ — და კითხვა ხშირ კითხვად იქცევა.

## გაუგზავნეთ ცვლილებები კლიენტებს

თქვენი ცვლილებები კლიენტებამდე მაშინვე არ აღწევს. ყოველი გვერდის თავზე ზოლი გაჩვენებთ, რამდენი ცვლილება ელოდება. დააჭირეთ **ცვლილებების გამოყენება**: ასისტენტი ხელახლა იწყობა, რამდენიმე სატესტო საუბარს გადის და ქვეყნდება. თუ შემოწმება ვერ გაიარა, ეკრანი გაჩვენებთ წარუმატებელ საუბარს და გვერდს, სადაც ამის გასწორება შეიძლება.

## გაასწორეთ არასწორი პასუხი

1. გახსენით საუბარი [შემოსულში](inbox) და ნახეთ, რა იკითხა კლიენტმა.
2. დაამატეთ ან გაასწორეთ ფაქტი პროფილში ან ცოდნაში.
3. იგივე კითხვა დასვით ეკრანზე **გამოცდა**.
4. გამოიყენეთ ცვლილებები.

> გამოცდილთათვის: **განახლებები და შემოწმებები** — ყველა გამოქვეყნებული განახლება თავისი შემოწმებებით; შეგიძლიათ წინაზე დაბრუნდეთ.
