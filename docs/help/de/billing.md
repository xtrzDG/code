# Tarif und Abrechnung

Alles finden Sie unter **Einstellungen → [Tarif und Abrechnung](cabinet:settings/billing)** (nur für Inhaber).

## Die kostenlose Testphase

Die Testphase beginnt von selbst, wenn der Assistent live geht, sodass jeder Testtag mit echten Kunden verbracht wird. Während der Testphase wird nichts berechnet. Einige Tage vor dem Ende erinnert Sie das Dashboard an die Zahlung.

## Tarife und Nutzung

Jeder Tarif enthält eine Anzahl Dialoge und Sprachminuten pro Monat; die Anzeigen zeigen, wie viel verbraucht ist. Die Preise sind in der Währung Ihres Landes. Sie können den Tarif jederzeit wechseln.

## Zahlung und Rechnungen

Sie zahlen per Karte auf der sicheren Zahlungsseite. Rechnungen erscheinen unter **Rechnungen**, wenn Sie zahlen oder die Testphase endet.

## Wenn eine Zahlung fehlschlägt

Der Assistent arbeitet während einer Nachfrist weiter, bis Sie zahlen; das Dashboard zeigt, wie viele Tage bleiben. Danach pausiert er, bis die Zahlung durchgeht, und nichts geht verloren.

## Kündigen

Sie können jederzeit kündigen: Der Assistent arbeitet bis zum Ende des bezahlten Zeitraums.

> Fragen zu einer Rechnung oder zu den Firmendaten darauf? Schreiben Sie uns unter **Hilfe und Support**.
