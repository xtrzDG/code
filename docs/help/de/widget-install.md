# Website-Chat

Der Website-Chat ist von Anfang an eingeschaltet. Besucher klicken auf die Schaltfläche in der Ecke Ihrer Website und sprechen in ihrer Sprache mit dem Assistenten.

## Auf Ihre Website bringen

1. Öffnen Sie **Assistent → [Kanäle](cabinet:assistant/channels)** und suchen Sie den **Code für Ihre Website**.
2. Klicken Sie auf **Code kopieren**.
3. Fügen Sie ihn auf jeder Seite vor dem schließenden `</body>`-Tag ein oder in die Einstellung „Eigener Code“ Ihres Website-Baukastens (WordPress, Tilda, Wix, Shopify und andere haben eine).
4. Öffnen Sie Ihre Website und prüfen Sie, ob die Chat-Schaltfläche erscheint.

## Das Aussehen

Wählen Sie unter **So sieht der Chat auf Ihrer Website aus** Ihre Markenfarbe und die Ecke der Schaltfläche. Die **Live-Vorschau** zeigt den Chat so, wie Besucher ihn sehen, noch vor dem Speichern.

## Keine Website?

**Kanäle → Teilen** liefert Ihnen den Link zu Ihrer eigenen Chat-Seite, einen QR-Code (PNG oder SVG) und eine druckbare Karte für Tische, Theke oder Tür. Setzen Sie den Link in Ihr Instagram-Profil, Ihren Google-Maps-Eintrag oder Ihre E-Mail-Signatur.

> Der Code enthält keine Geheimnisse: Sie können ihn bedenkenlos überall auf Ihrer Website einfügen.
