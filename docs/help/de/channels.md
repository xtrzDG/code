# Wo Ihre Kunden schreiben und anrufen

Öffnen Sie **Assistent → [Kanäle](cabinet:assistant/channels)**. Jede Kanalkarte zeigt, ob der Kanal verbunden ist, wann er zuletzt funktioniert hat und, falls etwas kaputt ist, was zu tun ist.

| Kanal | Was Sie brauchen | Zeit |
| --- | --- | --- |
| Website-Chat | Zugang zu Ihrer Website oder einfach den Link zu Ihrer Chat-Seite | 2 Minuten |
| Telegram | Ein Telegram-Konto | 2 Minuten |
| WhatsApp | Eine für die WhatsApp Business Platform registrierte Nummer | einige Tage für die Prüfungen von Meta |
| Instagram, Messenger | Eine Facebook-Seite (und ein professionelles Instagram-Konto) | 15 Minuten |
| Telefon | Eine Nummer von uns und eine Rufumleitung auf Ihrem Telefon | 5 Minuten |

## Ein Kanal zeigt einen Fehler

Die Karte sagt, warum: Meist wurde ein Token widerrufen oder ein Passwort beim Anbieter geändert. Klicken Sie auf **Angaben aktualisieren**, geben Sie die neuen Angaben ein, und der Assistent antwortet dort wieder. Nachrichten, die eingingen, während der Kanal ausgefallen war, gehen nicht verloren.

> Keine Website? Teilen Sie stattdessen den Link zu Ihrer Chat-Seite: **Kanäle → Teilen** liefert den Link, einen QR-Code und eine druckbare Karte für die Tische.
