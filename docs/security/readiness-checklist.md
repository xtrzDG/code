# Readiness checklist: a secure, finished platform

What a multi-tenant AI voice and chat assistant for EU small businesses must
satisfy before it is sold, and where this repository stands on each point.
The items with their full requirement, rationale and verification steps are
in [readiness-checklist.json](readiness-checklist.json).

Sources: OWASP ASVS 5.0 (level 2), OWASP Top 10:2025, OWASP API Security Top 10
2023, OWASP Top 10 for LLM Applications 2025 and for Agentic Applications 2026,
the EU AI Act (Art. 4 and 50), GDPR, the ePrivacy directive and the Italian
Garante's guidelines, PCI DSS v4.0.1 SAQ A, the European Accessibility Act and
WCAG 2.2, AGCOM rules, NIS2, the EU Data Act, and the security review skills of
Trail of Bits (insecure-defaults, sharp-edges, entry-point-analyzer,
supply-chain-risk-auditor, agentic-actions-auditor) and Anthropic's
claude-code-security-review.

Verified against the code on 2026-11-03: done 89, partial 26, gap 0, owner action 17, not applicable 4 (of 136).

Status: **Done** means implemented and proven by a test or a CI gate (the
evidence names both). **Partial** names what is still missing. **Owner
action** is outside the code (a lawyer, a provider console, a contract, DNS,
a paid penetration test). An item that is done in code can still list an
owner step. Review this file with the threat model
([threat-model.md](threat-model.md)) at least once a quarter.
