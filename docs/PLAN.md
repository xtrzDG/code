# План работ — Assistant Workshop (концепция v2)

Рабочий чеклист Python-бэкенда и кабинета владельца по [концепции v2](concept.md) (техническое задание —
разделы 1–15), [архитектуре](architecture.md) и [соглашениям](conventions.md).
Каждая итерация берёт следующие незакрытые пункты, реализует их, прогоняет проверки
(`uv run ruff check . && uv run mypy . && uv run pyright && uv run pytest`),
отмечает пункты и делает коммит.

Кабинет владельца (анкета и разделы ТЗ §8) — Next.js в `web/`; он ходит в HTTP API
бэкенда через свои серверные маршруты. Проверки кабинета: `cd web && npm run lint &&
npm run typecheck && npm test && npm run build`.
