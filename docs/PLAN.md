# План работ — Assistant Workshop

Рабочий чеклист бэкенда по [концепции](concept.md) и [архитектуре](architecture.md).
Каждая итерация берёт следующий незакрытый пункт, реализует его, прогоняет проверки
(`uv run ruff check . && uv run mypy . && uv run pyright && uv run pytest`),
отмечает пункт и делает коммит.
